# Database Schema Overview

Bell24h-OS utilizes a normalized PostgreSQL database, managed via Supabase.

### Core Modules
- **Organizations/Users**: Profile management, roles, RLS.
- **AI/Prompts**: Provider management, prompt orchestration.
- **Orchestrator**: Job queues, workers, scheduling.
- **Industry Intelligence**: Master business data hierarchy.
- **Context Engine**: Reusable context profiles.
